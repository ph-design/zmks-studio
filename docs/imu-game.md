# 姿态、校准与固件兼容性

当前组合：键盘 preview.12、Hub 0.6.9。界面与固件分别构建；固件源码见
[固件 PR](https://github.com/ph-design/ph_lite-zmk-config/pull/3)。
[历史说明与验证](imu-game-history.md)保留各轮变更记录，当前行为以下文为准。

## 姿态与校准

模型为无键帽、无阴影的抽象块体，橙色面表示空格键所在的前侧。相机居中从
前上方观察，后沿略窄于前沿。姿态及数值相对已校准平面显示；三轴加速度计
不能测量航向或位置，快速移动、敲击和失重会干扰重力倾角估计。

日常点击“放平校准并应用”，松开双手并保持静止约1秒。客户端对至少8个连续
有效样本求均值并应用中心，保留既有XY交换和极性。移动超过35mg、不平放、
无效或间隔超过350ms的样本重置采样窗口，8秒未完成提示重试。采样期间禁用
参数编辑／进入游戏模式，离开或换连接清理采样与迟到应答。顶部保存后持久化。

仅平放无法识别XY轴方向。需要时展开底部“高级轴向设置”，跟随动作模型和
蓝色边缘高亮，依次平放、抬左沿、先放平再抬后沿采样；识别后应用参数并再
执行放平校准。原始XYZ与中心参数留在高级区。

## 串口与 BL

| Hub 接口 | 系统报告名称                      | 用途                      |
| -------- | --------------------------------- | ------------------------- |
| MI_00    | PH Hub - Management (AT)          | 接收器状态、灯效和BLE外设 |
| MI_02    | PH Hub - Keyboard Config (Studio) | 所选键盘的无线配置        |

先连接管理接口，再选在线键盘。Hub 0.6.9提供独立USB接口／功能名称；浏览器
选择器由系统绘制，网站不能改名。旧固件仍保留接口提示与AT应答检查，桌面
端按接口角色匹配同一接收器。COM编号随系统变化，不能作为永久身份。

Hub通过已有AT+BL进入UF2；USB键盘通过明确bootloader_version能力检测开放
受解锁保护的core.enter_bootloader请求。键盘需USB直连，无法经无线让它成为
此PC的USB移动磁盘。进入前保存修改。

preview.12修复CDC FIFO满时UART回调堵住USB工作队列：单次至多64字节，按实际
写入数推进并等待完成回调续传。用户已确认USB Studio连接恢复。此前的整帧
发送流控、USB管理优先和停止后迟到回调保护保留。

## 协议与游戏模式

imuVersion=1：请求17读取配置、18应用、19显式开启／关闭模式；LiveState字段
6..15推送原始XYZ、采样时间、有效性、模式、模拟轴、横滚／俯仰和支持状态。
配置包含来源、范围、死区、滤波、反向、XY交换、XYZ极性和两轴中心，保存至
版本化imu_game/v1；模式只驻留RAM。没有重用旧字段。

姿态计算约50Hz，USB输出端遥测约25Hz，无线约10Hz；拥塞丢弃旧快照，页面
样本间平滑显示。650ms停更保护仍保留，异常时保持最后有效姿态，模拟轴回中。

实验游戏模式支持USB／2.4G单轴HID，Hub为两把键盘提供独立报告ID4/5，未实现
BLE轴或XInput。开启期间暂停拿起锁定和敲击，普通输入保留。页面串行续期、
固件租约3秒；退出／失效／端点变化请求回中，Hub每peer另有250ms轴超时。
请勿在模式开启时收纳。主机或USB停止响应时不能保证主机立即消费回中报告。

## 代码入口与验证边界

- ImuPanel.tsx：配置、页面生命周期、引导采样与显式模式。
- KeyboardPose.tsx：抽象模型、前侧标记、动作示意与动画。
- poseMath.ts：相机投影、角度回绕与稳定采样，纯计算可独立测试。
- imuProtocol.ts / imuLease.ts：新增字段编解码与有界串行续期。
- receiverPorts.ts / ReceiverAccess.tsx：统一接口名称、角色与连接入口。
- bootloaderProtocol.ts / KeyboardBootloader.tsx：能力检测及受限BL操作。

当前41项测试／271断言，TypeScript和生产构建通过。浏览器演示覆盖抽象模型、
无键帽／阴影、一次校准及三步高亮引导。Hub0.6.9已刷入，Windows实际报告两个
独立名称，配对配置保留，故障计数为0。实机输入、游戏、时延、续航和长期射频
稳定性须分别验证，不能用管理RPC响应或演示模式代替。

性能模式尚未实现。当前按下防抖2ms、USB轮询1ms不会因关闭后台任务自动缩短；
潜在收益应通过普通／并发负载下真实输入的P50/P95/P99、丢键和重传测量确定。
