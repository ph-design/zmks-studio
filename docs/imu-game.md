# 姿态与体感游戏 preview.10 / Hub 0.6.8

## 功能与边界

LIS2DH12 只测三轴加速度。模型表示相对重力的俯仰、横滚及翻转，不测航向或空间位置。快速移动、敲击和失重会干扰重力估计；加速度模长不在 700..1300 mg 时标为无效、模拟轴回中。传感器缓存超过 150 ms 不可用时退出模式。该有效性检查不能排除所有线性加速度，不是完整六轴融合。

ZMKs → 体感 → 姿态与体感：平放采样，再抬左沿，再先放平抬后沿，应用轴映射。中心按钮以当前倾角设置转向零点。映射支持 XY 交换及映射后 XYZ 反向，仅适用于本键盘平面安装方式，不是任意安装矩阵校准。校准需用户缓慢移动、停稳采样；该映射只作用于姿态/游戏，不修改拿起锁定的坐标处理。顶部保存持久化参数，游戏模式永不持久化。

可选择前后倾斜（roll）或左右倾斜（pitch），默认左右倾斜。最大转角 5..90°（默认45），死区0..10°且小于最大转角（默认2），滤波0..200ms（默认60），支持反向、独立两轴中心。输出是一个有符号16位绝对 X 轴，范围-32767..32767，约50Hz更新机会。不是多圈方向盘，推荐在中心±45°范围内使用。

## 明确进入与退出

仅 USB 和2.4G可进入，BLE轴输出不实现。新增USB描述符仅在USB注册时拼接，不修改共享BLE报告映射。USB使用Joystick应用集合/报告ID4；Hub为两把键盘提供独立的ID4/ID5应用集合。游戏需支持通用HID/DirectInput；不模拟Xbox控制器，不保证XInput-only兼容。

第一版需保持此页面连接。用户显式开启，客户端一次只续期一个请求，约900ms后再续期；模式租约3秒。离开页面停止续期并请求关闭，迟到成功响应再次请求关闭。连接中断、程序退出或请求超时后固件租约到期自动退出。活动模式暂停拿起锁定和敲击动作，保留普通键盘输入；请勿在游戏模式下收纳。退出后恢复拿起锁定并重新确认放稳。该模式是有意取代收纳保护的明确例外。

模式退出、传感器缓存失效、输出端切换均请求旧端轴回中。USB忙时重试；2.4G接收器独立250ms轴状态超时，断开/新会话/解除配对时也清零。无法在主机/USB完全停止响应时保证主机立即消费回中报告。

## 数据与调度

RPC Capabilities.imu_version字段12=1。Request17 get_imu_game_config(bool)，18 set_imu_game_config，19 set_imu_game_mode(bool)；Response17 config，18/19 acceptance。config字段依次为source、range_deg、deadzone_deg、smoothing_ms、invert、swap_xy、flip_mask、center_roll、center_pitch，后两项为有符号百分之一度。现有字段不变。参数保存在独立版本化 imu_game/v1，模式租约只在RAM。

LiveState新增6..15：x/y/z mg，sample_time，tilt_valid，game_active，game_axis，roll_cdeg，pitch_cdeg，game_supported。体感页面订阅时约25Hz推送，页面离开关闭；无需每帧RPC查询。姿态滤波/角度计算在独立线程，未订阅且非游戏时暂停。沿用传感器缓存，不在按键路径读I2C。

加密无线体0xd1 + little-endian int16轴，沿用每peer加密/重放保护。轴发送与按键/心跳放在同一系统工作队列，单独使用本地报文，不为轴输出清空按键队列。USB轴发送忙时跳过并重试，不在键事件上增加姿态等待。共享总线/射频的真实延迟仍需测量，不能把主机测试视为游戏响应时间基准。

Hub不合并两把键盘的轴。使用最新值和独立更新时间，轴超时在USB输出循环中处理，持续按键流量不会阻止回中。USB重连强制刷新轴状态；未变化的轴降低重复发送频率。

## 验证范围

已完成真实 imu_game.c 主机测试：参数边界、死区/限幅/反向/跨角度边界、明确进入、租约过期、传感器失效、输出端切换、USB忙时回中重试、显式保存。真实Hub描述符检查ID及位数，实际USB循环覆盖双peer隔离、持续键盘流量下的超时回中与时钟回绕。既有运动保护、无IMU、电源、驱动、BL及加密遥测回归通过。

前端协议测试覆盖真实RPC帧的读取/应用/读回/模式开启关闭、带符号角度和通知、无重叠续期及迟到响应关闭。浏览器演示验证模型动态、模式参数锁定/退出、导航退出，以及受控模拟三步轴向校准。演示不接触实物。

三个键盘目标及Hub从固定SDK构建成功。未刷写任何设备；真实Windows控制器枚举、游戏兼容性、两个控制器实际并发、回中时序、输入延迟、功耗、重启持久化和长时间射频稳定性仍待用户测试。
