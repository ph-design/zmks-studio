# 布局与文案修复记录

日期：2026-11-08。继续保留首轮根字号及缩放按钮修复；本轮完成审查报告中的七项调整，并统一全局可见文案。

## 布局修复

| 问题 | 实现与验证 |
| --- | --- |
| 主按钮文字不可读 | 公共按钮样式不再包含与主色冲突的透明背景；主、次、危险状态分别指定背景。实测主按钮为蓝底白字。 |
| 组合键右栏溢出 | 按编辑容器宽度决定单双栏；数值控件改为标签独占一行，滑条可收缩。1280px 和 1600px 宽下均无横向溢出，超时数值框完整可见。 |
| 绑定编辑器挤压 | 可用宽度不足时，将分类和行为列表切换为两个下拉框，复用原有选择逻辑；窄参数区域将修饰键移至键码列表下方，并允许滚动。960px 窗口中参数区由 176px 扩展为 544px；实际分类和行为切换通过验证。宽屏恢复列表布局。 |
| 灯光自适应失效 | 原样传递 `auto`，由实际画布空间计算缩放。1280px 下模拟全尺寸键盘完整显示，不再固定为 80%。 |
| 敲击历史区零宽 | 测试区改为自适应网格，事件历史独占一行；限制测试区域占高并允许滚动。960px 窗口中历史区宽约 486–496px，空记录状态有明确提示。 |
| 小屏二级侧栏占宽 | 新增共用 `FeatureRail`，767px 以下改为顶部可展开区域。折叠时约 41px 高，编辑区使用全部宽度；展开后由整个侧栏内容统一滚动，保留图层等底部操作。 |
| 语言选项截断 | 使用语言下拉框，保留五种语言的完整名称。390px 宽度下已验证。 |

## 文案与型号

- 中文“拍一拍”统一为“敲击检测”，“入睡”改为“休眠”；“给双击让路”等口语化说明改为双击识别窗口、延迟触发等明确术语。
- 补齐敲击测试的中文和英文词条，包括识别事件数、最近事件、空记录提示、超阈值未识别次数和识别说明。原先直接显示英文的测试区域现已中文化。
- 中文界面的 dongle 统一为“接收器”；同步调整连接、解锁提示、演示入口和 Tap-Hold 说明。
- 补齐设备页“刷新信息”“复制全部”“恢复出厂设置”及灯光页“灯光效果”“颜色”等缺失中文。固件返回的行为名称、灯效名称和型号原值予以保留。
- 型号来自 `motion.capabilities.sensor`，生成协议类型的示例值为 `lis2dh12`。二级菜单底部现在明确显示“传感器型号: lis2dh12”；空值显示“未提供”。采用“传感器型号”以准确对应固件字段，不推断其传感器能力。
- 型号标签及紧凑编辑器的新选择提示补齐全部五种语言；其余文案润色以中文和英文为主。
- 详细方向检测说明收纳于“识别说明”，主界面只显示用户操作所需信息。
